# Dr. Ayman Tarek — Clinic Website

[![Dr. Ayman Tarek website](https://raw.githubusercontent.com/akkrrammm/akkrrammm/main/assets/ayman-tarek.jpg)](https://dr-aymantarek.com/)

> Official bilingual (Arabic / English) website for Dr. Ayman Tarek, with animated UI and a complete admin dashboard.

🔗 **Live site:** [dr-aymantarek.com](https://dr-aymantarek.com/)

## ✨ Features

- 🌍 Bilingual Arabic (RTL) & English experience
- 📄 Pages: Home, Doctor Profile, Services, Blog, Videos, Contact, Privacy Policy & Terms
- 🎬 Smooth animations with Framer Motion
- 🛠️ Admin dashboard to manage testimonials, FAQs, media, SEO, users and site settings
- 🔐 Secure admin authentication with user management
- 📱 Fully responsive, mobile-first design

## 🛠️ Tech Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · Framer Motion · Supabase · TanStack Query

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and add your Supabase keys before running.
